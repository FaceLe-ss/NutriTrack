# 🍏 NutriTrack — PWA-трекер калорий, КБЖУ и Хлебных Единиц (ХЕ) по фото

Минималистичное веб-приложение (PWA) для iPhone и ПК, разработанное для быстрого подсчета калорий, макронутриентов и Хлебных Единиц (ХЕ) с помощью мультимодального ИИ (Google Gemini API).

---

## ✨ Основные возможности

* **📷 Сканирование блюд по фото:** нативное открытие камеры iPhone, быстрое сжатие снимка на клиенте и мгновенное распознавание блюда, размера порции и КБЖУ.
* **🍞 Автоматический расчет Хлебных Единиц (ХЕ):** расчет по формуле **`1 ХЕ = 10 г чистых углеводов`** (`bread_units = carbs / 10`). Значение ХЕ выводится в результатах сканирования, карточках блюд и суммируется за день.
* **🎙️ Голосовой ввод:** надиктовывание блюд простыми словами (*«съел тарелку гречки и две куриные котлеты»*).
* **📊 Минималистичный экран:**
  * Анимированная кольцевая диаграмма оставшихся и съеденных калорий.
  * Индикаторы компонентов КБЖУ (Белки, Жиры, Углеводы) с процентами от дневной цели.
  * Виджет общего количества Хлебных Единиц за день.
  * Хронологический список приемов пищи за сегодня с превью фото и раскладкой БЖУ.
* **🔒 Конфиденциальность (100% Client-Side):**
  * Все данные хранятся локально на вашем iPhone в `IndexedDB`.
  * Личный API-ключ Gemini хранится в зашифрованном хранилище браузера и передается напрямую в Google API без сторонних серверов.

## 🚀 Запуск и тестирование на iPhone (по локальной сети)

1. Запустите файл `start.bat` (или выполните `python serve.py` в папке проекта).
2. Сервер покажет ваш локальный Wi-Fi адрес, например:
   ```
   http://192.168.1.124:8000
   ```
3. Откройте эту ссылку в браузере **Safari** на iPhone (компьютер и iPhone должны быть подключены к одному Wi-Fi).
4. **Установка на домашний экран (как родное приложение):**
   * В Safari нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана).
   * Выберите **«На экран «Домой»» (Add to Home Screen)**.
   * Нажмите **«Добавить»**.
   * Запустите приложение с иконки на рабочем столе — оно откроется на весь экран без рамок браузера!

## 🔑 Настройка ИИ и работа БЕЗ VPN (в РФ и других регионах)

NutriTrack использует провайдер **OpenRouter**, который работает в РФ и любых регионах напрямую **без всяких VPN и прокси**:

1. Зарегистрируйтесь на сайте [openrouter.ai](https://openrouter.ai/) (сайт и API работают без VPN).
2. Создайте ключ в разделе **Keys**.
3. В приложении NutriTrack в настройках вставьте ключ в поле **«Свой OpenRouter API Key»**.
4. Выберите рекомендованную быструю и точную модель `google/gemini-2.5-flash-lite` или бесплатную `particle-ai/particle-1:free`.
5. Нажмите кнопку **«Проверить»** и сохраните. Приложение работает быстро, надежно и без VPN!

Чтобы приложение было доступно везде без привязки к домашнему компьютеру:

* **Cloudflare Pages / Vercel / GitHub Pages:**
  Просто загрузите файлы из этой папки в репозиторий GitHub или перетащите папку в панель [Cloudflare Pages](https://pages.cloudflare.com/). Вы получите постоянный адрес с бесплатным SSL (`https://ваш-проект.pages.dev`), на котором PWA и камера работают идеально.
